# Dostaffkin — Доставка посылок

Приложение для расчёта стоимости доставки посылок, оформления заявок и отслеживания статуса отправлений.

## Основной функционал

- Расчёт доставки – выбор маршрута (Яндекс.Карты), размера посылки и скорости доставки с автоматическим расчётом цены и срока.
- Оформление заявки – отправка контактных данных и параметров доставки через API.
- Отслеживание – проверка статуса отправления по номеру заявки.

## Технологический стек

- Язык: TypeScript
- Фреймворк: Angular (standalone components)
- Карты: Яндекс.Карты API 2.1
- HTTP-клиент: `@angular/common/http`
- Стили: CSS (адаптивная вёрстка)

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
ng serve

# Сборка проекта
ng build
```

Приложение будет доступно по адресу `http://localhost:4200`.
